# Gate P1 — moteur d'inférence : preuves

> **✅ Gate P1 VALIDÉ par l'utilisateur le 2026-11-03** : A1.1 → A1.7 et le calibrage P1.10 démontrés.
> Critères : `development-plan.md` §P1.

## Comment rejouer

```bash
# sans GPU (CI à chaque push)
cd backend && uv run pytest && uv run ruff check && uv run mypy

# sur GPU réel : 13 tests « gpu », ~6 min 30, pic ≈ 8,5 Gio sur la carte
docker compose --profile gpu-test build worker-test
docker compose --profile gpu-test run --rm worker-test
```

Les tests GPU sont en deux modules joués l'un après l'autre : `test_idol_adapter.py` garde Idol
chargé dans le processus de test, `test_idol_process.py` en charge un autre dans un processus
d'inférence. Deux copies simultanées (~2 × 7,3 Gio) ne tiendraient pas sur 12 Go.
