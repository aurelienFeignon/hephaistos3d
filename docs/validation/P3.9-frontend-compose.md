# P3.9 — Image et service Compose du frontend

État : implémenté et vérifié le 2026-11-09, en Docker CPU sur projet et données temporaires. Le gate P3
n'est pas validé. Aucun déploiement permanent n'a été lancé.

## Implémentation

- `deploy/frontend.Dockerfile` : construction en deux étapes, image `standalone` de Node 24, épinglée par
  empreinte, exécutée en UID 1000. Le jeton n'est pas utilisé à la construction.
- `compose.yaml`, service `frontend` : seul port publié de la pile, lié à `HEPHAISTOS_BIND_ADDR`
  (`127.0.0.1` par défaut) sur `HEPHAISTOS_PORT` (3030). L'API reste sur le réseau `backend`, interne ;
  le réseau `edge` existe parce qu'un réseau interne ne peut pas publier de port.
- Le conteneur n'a aucun montage de données et reçoit uniquement ses propres réglages.
- `.dockerignore` reste une liste d'inclusion : ni `.env`, ni `node_modules`, ni `.next`, ni tests.

## Choix et limites

- Avec un autre `HEPHAISTOS_PORT` ou une autre adresse, il faut adapter `FRONTEND_ALLOWED_ORIGINS` et
  `API_ALLOWED_ORIGINS`, faute de quoi le proxy refuse les mutations.
- L'ouverture au LAN reste subordonnée à une politique d'accès pour les utilisateurs du frontend.
- `npm start` affiche un avertissement avec `output: standalone`, mais continue de servir la page et ses
  fichiers statiques. L'image utilise `server.js`.
- Le build de l'image ne fait pas partie de la CI.

## Vérifications

Images construites depuis `compose.yaml` (frontend : 280 Mo), projet Compose isolé, données et jeton
temporaires, port 3039, sans GPU ni worker :

- démarrage dans l'ordre migration, API saine, frontend sain ; santé rétablie après redémarrage ;
- parcours Chromium à travers le conteneur : modèles, import multipart, file avec motif `NO_WORKER`,
  vignette, suspension, protection, annulation, suppression, thème et polices ;
- rejets réels : 422 hors bornes, 413 corps trop grand, 403 origine étrangère, 400 hôte étranger, 404 sur
  la documentation API et la page de sonde ;
- durcissement : racine en lecture seule, UID 1000, capacités retirées, `no-new-privileges`, 1 Gio,
  256 processus, aucun montage, aucun message `EROFS` ni erreur au journal ;
- exposition : seul `127.0.0.1:3039` écoute ; l'API n'a aucun port publié ;
- secret : ni le jeton de banc ni un jeton réel présents dans l'image ou son historique, recherche validée
  par un témoin positif ; aucun `.env` ni fichier de test embarqué.

Après arrêt, conteneurs, réseaux et images de validation sont supprimés, et les conteneurs existants de
la machine sont inchangés (identifiants et dates de démarrage identiques avant et après).

Le parcours avec un worker réel a été validé hors conteneur en P3.5 à P3.8. 3 gardes `compose` ajoutées et
une adaptée (541 tests backend sans GPU), observées en échec avant implémentation ; 220 tests frontend,
ESLint, `tsc` et build verts.
