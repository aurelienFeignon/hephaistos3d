# P4.8 — Rétention et protection dans l'interface

État : implémenté et vérifié en local le 2026-11-11, sans GPU. Le gate P4 n'est pas validé.

## Implémentation

- **API** : la représentation `Generation` publie `auto_delete_after`, l'instant après lequel la
  rétention automatique supprime la génération (`finished_at + STORAGE_RETENTION_DAYS`). Il vaut `null`
  pour une génération non terminée, protégée, ou quand la rétention est désactivée. Le calcul reprend
  exactement les critères du janitor (statut terminal, non protégée, rétention active), pour que
  l'interface n'ait pas à les dupliquer. Contrat : `docs/api-contract.md` §3.
- **Interface** : une section « Conservation » dans le détail d'une génération terminée.

| Situation | Message |
|---|---|
| Protégée | Protégée : jamais supprimée automatiquement. |
| Date connue | Supprimée automatiquement après le *11 décembre 2026 à 16:48*. Protégez-la pour la conserver. (en couleur d'alerte à moins de 3 jours) |
| Rétention désactivée | Conservée sans limite : la suppression automatique est désactivée. |
| Non terminée | rien |

  Protéger ou déprotéger relit la génération : la date disparaît puis revient sans rechargement.
  La protection reste aussi affichée dans la bibliothèque (« protégée », filtre « Protégées »), comme
  depuis P3.6.

## Vérifications

- Backend : 547 tests sans GPU (3 nouveaux), Ruff, format, mypy strict. Dont un test qui lie l'API au
  **vrai** janitor : une génération annoncée une seconde avant l'instant présent est supprimée par
  `run_once`, celle annoncée une seconde après est conservée.
- Mutations détectées puis restaurées : date publiée pour une génération protégée ; décalage d'un jour
  entre la date annoncée et la règle du janitor (2 tests rougissent) ; seuil d'imminence neutralisé.
- Vitest : 250 tests (5 nouveaux). ESLint, `tsc`, `api:check` verts (types régénérés).
- Playwright : 11 parcours verts, dont le nouveau parcours P4.8 (date affichée, protection, date rendue).
- Capture Chromium du panneau de détail : section lisible entre « Télécharger » et « Paramètres effectifs ».

## Limites

- L'imminence se juge à l'instant d'ouverture du détail, pas en continu : le seuil se compte en jours.
- La date est affichée dans le fuseau du navigateur.
