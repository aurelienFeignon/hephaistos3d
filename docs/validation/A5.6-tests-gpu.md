# A5.6 — Tests GPU rejoués

État : joués le 2026-11-17 (RTX 5070, image `worker-test`, `docker compose --profile gpu-test run --rm worker-test`).
Le gate P5 n'est pas validé.

## Premier passage, sur `0e6fec6` : 10 réussis, 3 échoués

Les trois cas de `test_cli_produces_valid_artifacts_for_each_reference_image` (A1.2) échouaient tous
sur `json.loads(result.stdout)`. La génération réussissait (code 0, artefacts et métriques
présents), mais le stdout de la CLI commençait par une ligne de journal :

```
{"event": "Could not reach the Hub (… offline mode is enabled …). Using cached commit hash …",
 "level": "warning", "service": "inference", "logger": "huggingface_hub.hf_api", …}
```

**Cause** : depuis les journaux JSON corrélés (`39668b0`, 2026-11-05), le processus d'inférence
configure son journal sur stdout. Dans le worker, c'est sans effet : Docker capture les deux flux.
Sous la CLI, l'enfant hérite du stdout du parent, réservé au résumé JSON. Les tests GPU avaient été
joués pour la dernière fois le 2026-11-03, et la CI ne les joue pas : la régression est restée
invisible douze jours.

**Correctif** : l'enfant configure son journal sur stderr (`worker/inference.py`). Un test sans GPU,
`test_child_logs_go_to_stderr_never_to_stdout`, garde ce contrat. Il échoue sans le correctif
(vérifié par mutation) et passe avec.
