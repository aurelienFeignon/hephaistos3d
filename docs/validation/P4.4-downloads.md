# P4.4 — Téléchargements (PLY, aperçu, caméra)

État : implémenté et vérifié en local le 2026-11-11, sans GPU. Le gate P4 n'est pas validé.

## Implémentation

- Le panneau de détail d'une génération terminée porte une section « Télécharger », disposée comme
  dans la maquette validée (D16) : `splat.ply` en action principale avec sa taille, puis « Aperçu PNG »
  et `camera.json`. Seuls les fichiers présents sont proposés ; rien n'est proposé avant la fin.
- Les liens pointent sur `download_url`, l'URL que l'API publie pour chaque artefact (par identifiant,
  jamais par chemin). L'attribut `download` reste sans valeur : le nom vient de `Content-Disposition`,
  construit par le serveur.
- Le serveur nomme désormais `hephaistos-<génération>-splat.ply`, `-preview.png` et `-camera.json`.
  L'ancienne construction (`<kind>` + suffixe) doublait l'extension : `…-splat_ply.ply`. Contrat
  mis à jour (`docs/api-contract.md` §5).
- La mise en forme des tailles (`formatMegabytes`) est partagée avec le visualiseur.

## A4.4 — le fichier téléchargé est le fichier stocké

| Niveau | Ce qui est comparé |
|---|---|
| API (pytest, 3 types d'artefact) | octets servis = octets du fichier sur disque ; `ETag` = SHA-256 des octets servis ; `Content-Disposition` exact ; type MIME |
| Navigateur → proxy Next → API (Playwright) | pour chacun des trois liens : nom proposé par le navigateur, taille et SHA-256 du fichier enregistré = `size_bytes` et `sha256` de l'artefact (calculés par le worker sur le fichier promu), `ETag` relayé = ce SHA-256, octets identiques à une lecture directe |

## Vérifications

- Backend : 544 tests sans GPU (3 nouveaux, rouges avant correction du nom), Ruff, format, mypy strict.
- Vitest : 243 tests (3 nouveaux). ESLint, `tsc` et `api:check` verts.
- Playwright : 10 parcours verts, dont le nouveau parcours A4.4.
- Mutations détectées puis restaurées : section affichée hors `COMPLETED` (Vitest), nom forcé côté
  client par `download="…"` (Vitest), `ETag` non relayé par le proxy Next (Playwright, `Received:
  undefined`).

## Limites

- Aucun contrôle visuel de la section n'a été fait (ni capture ni couleurs calculées).
- Le transfert d'un gros PLY (71 Mo) à travers le proxy reste à mesurer avec A4.1, sur le poste cible.
